# 擬似言語 / C# 表示切替

日付: 2026-08-27  
対象: FE Classroom Quiz（`index.html` / `quiz.js` / `questions.json`）

## 目的

科目B対策では擬似言語で解き、授業の C# 補助では C# で解けるようにする。問題バンクは増やさず、既存の `expr` / `code` と `pseudocode` を切り替えて見せる。

## 非目標

- 擬似言語用の別正答・別選択肢は作らない
- 言語フィルタ（出題バンク切替）は今のまま（`lang: csharp` のみ）
- 配色テーマ（夜間 / 教室）とは独立

## 表示モード

値は `ipa` または `csharp`。

- 保存キー: `localStorage` の `fe_quiz_codeview`
- 初回・未保存・不正値: `ipa`（擬似言語）
- 生徒用ロックでも切替可（ヘッダーは隠さない）
- 配色キー `glowadder-theme` とは別

## UI

ヘッダー右、配色セグメントの左に同じ `.seg` を置く。

- 擬似言語 / C#
- アクティブは配色ボタンと同じ見た目
- 出題中に切り替えたら、今の問題（または採点結果）を同じ問のまま描き直す
- セットの作り直し・タイマー再開はしない

## 出題中の本文

選んだモードのプログラムだけ出す。

- `csharp`: 既存どおり `code` があればそれ、なければ `expr`
- `ipa`: `pseudocode`（無ければ `autoPseudocode`）。行末・行頭の `// …` 注記は出題中は削除する（C# 添字の対応などがヒントになるため）

タグの言語名は、その問の表示言語に合わせる（`擬似言語` または `C#`）。

## 採点後

主表示は今のモードのプログラム。もう一方は折りたたみ（今の「擬似言語を表示」と同じトグル）。

- C# モード → トグルで擬似言語（注記ありでよい）
- 擬似言語モード → トグルで C#（`code` / `expr`）
- 復習・最終結果の各問も同じ規則

## C# 専用問

正答が言語で変わる問は擬似言語では出さない。

| id | 理由 |
| --- | --- |
| `cond-007` | `&&` 短絡 |
| `cond-008` | `\|\|` 短絡 |
| `cond-016` | `&&` 短絡（出力） |
| `cond-019` | `if (x)` が C# ではコンパイルエラー |

`questions.json` に `"csharpOnly": true` を付ける。

- 開始時の抽出で、モードが `ipa` ならこれらの問を候補から外す
- 途中で C# → 擬似言語にしても、すでに引いたセットは変えない。その問が `csharpOnly` なら **C# のまま表示**し、「この問は C# 専用」と小さく出す
- 擬似言語で開始したセットにこれらは入らない

## 既存 UI との関係

- 出題設定の「言語：C#」チェックはバンク用のまま。1言語しかないので今どおり隠してよい
- 初心者モードの日本語化は言語切替と独立

## ファイル

- `index.html`: セグメントボタン。FOUC 防止の先行スクリプトは不要（プログラム表示は JS 描画）
- `quiz.js`: モード読書き、抽出フィルタ、描画、途中切替
- `questions.json`: 上記 4 問に `csharpOnly`

## 確認

- 初回は擬似言語。再読込後も前回の選択が残る
- 擬似言語の条件式のみ 10 問に `cond-007` 等が混ざらない
- C# にすると短絡問が出うる
- 出題中の擬似言語に `// C#` 注記が出ない
- 採点後にもう一方の言語を開ける
- 夜間 / 教室切替は壊さない
